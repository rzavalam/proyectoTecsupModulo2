# ADR-001: Por qué usar Arquitectura Hexagonal

## Estado
Aceptado

## Fecha
2026-05-15

## Contexto
Sistema de Gestión Bancaria
Se ha desarrollado un aplicativo de "Banco Digital", un sistema bancario simple que permite:
Crear cuentas bancarias
Consulta Saldos
Transferir dinero entre cuentas


## Decisión
Hemos utilizado Arquitectura Hexagonal

## Alternativas Consideradas
1. Arquitectura en capas tradicional
2. Arquitectura Hexagonal - ELEGIDA

## Consecuencias
### Positivas
- Mayor desacoplamiento entre dominio e infraestructura.
- Facilita pruebas unitarias de los casos de uso.
- Permite reemplazar adaptadores sin modificar la lógica de negocio.
- Mejora la mantenibilidad y escalabilidad.

### Negativas
- Mayor cantidad de clases e interfaces.
- Curva de aprendizaje más alta.
- Incremento inicial en la complejidad del proyecto.
