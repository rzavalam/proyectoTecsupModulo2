# ADR-001: Sistema de persistencia (H2 vs Mysql)

## Estado
Aceptado

## Fecha
2026-05-15

## Contexto
Sistema de Gestión Bancaria
El proyecto necesita una base de datos sencilla para desarrollo y pruebas rápidas. Se busca minimizar la configuración inicial y permitir la ejecución inmediata del sistema.


## Decisión
Utilizar H2 Database como sistema de persistencia principal para el entorno de desarrollo.

## Alternativas Consideradas
1. MySQL
2. H2 Database - ELEGIDA

## Consecuencias
### Positivas
- Configuración rápida y sencilla.
- Base de datos embebida.
- Facilita pruebas y desarrollo local.
- No requiere instalación externa.

### Negativas
- No representa completamente un entorno productivo.
- Diferencias de compatibilidad frente a MySQL.
- Limitaciones para escenarios de alta concurrencia.
